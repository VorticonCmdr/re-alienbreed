[Format index](README.md) · Researched and inspected 2026-10-03

**Evidence status:** Verified byte identity with DAT preset.

## Identification and purpose

`SETUP.M32` is a 103-byte binary configuration record. It is byte-identical to `mt32/SETUP.DAT` and the extensionless `REM` file. It differs from root `SETUP.DAT` and `sb16/SETUP.DAT` only at offset `0x06`, where it contains `01` instead of `00`.

The filename and identity with the preset selected by [run.bat](../game/run.bat) identify this as an MT-32 configuration preset. Its stored format is the same as the setup-record family described in [`.DAT`](dat.md).

## Reading and remaining questions

Treat this as a fixed binary record, not MIDI music. Preserve unknown fields if comparing or copying a preset. The precise sound-setting field name at offset six, numeric enumeration, and remaining options have not been reverse engineered.
